Key concepts

Four steps from raw data to a map that holds up.

Most GIS mistakes happen between these steps. Knowing what each one is for makes them easier to catch.

◫

A layer is not the data

A layer is a view of a dataset with its own symbols and filters. Editing the layer's look never changes the source, but editing features does.

⊕

Define versus Project

Define Projection only labels data with the coordinate system it already uses. Project transforms coordinates into a new one.

%

Normalize before you map

Counts mostly show where people live. Rates and densities show whether something is unusually common there.

✓

Validate independently

Check a result by a different route, such as a manual sample or a second tool, before anyone relies on the map.
